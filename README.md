# Autonomous Robotaxi Simulation

A self-driving car simulation built in **Unity 6 (URP)** for a class showcase: a robotaxi drives itself
through a small city with traffic, signals, zebra crossings and pedestrians, with a Tesla-style
autopilot visualisation (lidar points, planned path, tracked vehicles and people).

## What it does
- **Autopilot** (`unity-src/Scripts/AutoPilot.cs`) used by the robotaxi and every traffic vehicle:
  lidar + path-sweep perception, V2I traffic lights, V2V following, pure-pursuit steering on a
  kinematic bicycle model, planned S-curve lane changes to pass parked obstacles and slow traffic.
- **Traffic rules**: stops on red, yields at zebra crossings, keeps right, no overtaking near
  crossings/signals/split junctions, keeps crossings and junctions clear, never reverses.
- **City**: street grid with 4 routes, signalised junctions and crossings, 70 varied buildings,
  street furniture, road works, a bus stop and a depot.
- **Pedestrians**: Mixamo characters that cross on the walk signal; press **P** for a jaywalker.

## Controls
| Key | Action |
|---|---|
| P | pedestrian jaywalks in front of the car |
| B | drop an obstacle in front of the car |
| V | full-screen autopilot view |
| M | toggle autopilot / manual (WASD) |
| C | change camera · T sensor rays |
| Space / R / H | pause / restart / help |

## Build & run
Requires Unity **6000.6.2f1** with glTFast (`com.unity.cloud.gltfast`).

```powershell
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Open          # build scene + player, launch
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -SimTest       # 6-minute automated traffic test
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Capture       # screenshots into Build\captures
```

C# sources live in `unity-src/` (copied into `UnityProject/Assets` by the build script).
The whole scene is generated by `SceneBuilder` (menu **Self Driving > Build Demo Scene**).

## Automated test
`RobotaxiSim.exe -batchmode -nographics -simtest <dir>` simulates 6 minutes of traffic with obstacles
and jaywalkers and checks every vehicle for contacts, wrong-way driving, leaving the road,
reversing, red-light running, stopping on crossings and long stops.
